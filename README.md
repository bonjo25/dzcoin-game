# DZ Coin HTML5 Game

هذه نسخة جاهزة للرفع والاستضافة كلعبة HTML5.

## محتوياتها
- index.html
- واجهة متجاوبة للهاتف وTelegram
- جمع عملات بالضغط
- حد يومي 100 ضغطة
- مكافأة يومية +50 DZC
- أفضل نتيجة
- مشاركة النتيجة عبر Telegram عند تشغيل اللعبة داخل Telegram
- تصميم DZ Coin داكن/ذهبي/أزرق

## مهم جدًا قبل الإطلاق

هذه النسخة تحفظ الرصيد في localStorage داخل المتصفح، لذلك هي **نسخة واجهة/تجربة** وليست نظام رصيد حقيقي.
لا تعتمد على الرقم الظاهر في الصفحة لمنح سحب مالي؛ يمكن للمستخدم تعديل بيانات المتصفح.

لجعل DZC حقيقيًا ومربوطًا بالبوت:
1. استضف اللعبة عبر HTTPS.
2. اجعل البوت يعالج CallbackQuery الخاص بـ game_short_name = dzcoin.
3. يفتح البوت رابط HTML5 اللعبة عبر answerCallbackQuery.
4. اجعل السيرفر الوسيط هو الذي يتحقق من المستخدم والنتيجة ويحدث قاعدة بيانات DZ Coin.
5. لا تضع BOT_TOKEN داخل JavaScript أو HTML.
6. يمكن استخدام setGameScore / getGameHighScores لنظام النتائج الرسمي في Telegram.

Telegram يوضح أن لعبة HTML5 تُفتح من خلال URL يقدمه البوت عند الضغط على زر اللعبة، وأن التحقق/تسجيل النتائج يحتاج خادمًا وسيطًا لأن توكن البوت لا يجب وضعه داخل اللعبة.

## الاستضافة
ارفع index.html إلى استضافة HTTPS مثل:
https://example.com/dzcoin/

ثم اربط هذا الرابط في كود البوت عند استقبال game_short_name=dzcoin.

## اختبار سريع
يمكن فتح index.html في متصفح عادي للتجربة.
لكن مشاركة النتيجة الخاصة بـ Telegram تعمل عند تشغيل اللعبة من داخل Telegram.
